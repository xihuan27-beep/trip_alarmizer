我是古淘寺的佛塔——这座寺庙的塔。今天想跟你讲讲我的名字是怎么来的。

你也看到了,我的身体是由一节节圆滚滚的部分层层叠起来的。在人们眼里,这看起来就像是把好几个葫芦叠在了一起。于是人们开始叫我"古淘",意思就是"葫芦塔"。跟其他寺庙那些尖尖的塔比起来,我算是长得比较圆润、朴素的了。不过,我还挺喜欢自己这副模样的。

但可别因为我长得朴素就小看我。古老流传下来的一部九卷本典籍里,记载着一个叫"世界巡游佛"的传说。在那个故事里,我以"韦卢瓦纳兰"这个名字出现——被列为传说中预言最为神圣的八座寺庙之一。虽然我外表看起来圆滚滚、平平无奇,但其实我拥有相当尊贵的地位呢。

关于我的外表,还有另一个故事。大约从1856年开始——换算成中国的年号,大约是咸丰六年,亚罗号战争(第二次鸦片战争)爆发的那一年——用欧洲的时间来说,正是克里米亚战争刚以《巴黎条约》告终的那段时期——随着与英国的柚木贸易日渐兴盛,缅甸人、掸族人和布朗族人开始大量涌入这一带。他们在此赞助宗教活动的同时,也带来了一种叫做"贡榜风格"的缅甸装饰艺术。我身上如今还能看到的那些别具一格的装饰,其实正是那时候传入的。
