我是禅那长老。曾是一位学问僧。今天想跟你简短讲讲这座寺庙——七塔寺的故事。

我曾经为狄洛卡拉王写过一部叫做"行为指南"的书。而那位狄洛卡拉王,正是修建了这座七塔寺的国王。想到当年我曾经指导过的人,后来竟留下了这样一座宏伟的寺庙,我心里不免生出一种奇妙的感慨。

即便在我离世之后,这座寺庙的故事也仍在延续。1511年——换算成中国的年号,大约是明武宗正德六年——用欧洲的时间来说,正是米开朗基罗即将完成西斯廷教堂天顶画的那段时期——这座寺庙举行了一场结界仪式。据说,在出席的二十来位僧人名单中,竟没有一人来自清迈。后世学者围绕这份名单,展开了一场关于某部古籍作者究竟是谁的争论。说实话,那个答案我也不知道。我不过是恰好认识修建这座寺庙的那位国王罢了。
