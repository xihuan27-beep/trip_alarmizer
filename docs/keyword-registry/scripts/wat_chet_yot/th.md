ข้าพเจ้าคือพระเถระจัน เคยเป็นพระนักปราชญ์ วันนี้ขอเล่าเรื่องสั้นๆ เกี่ยวกับวัดนี้ วัดเจ็ดยอด ให้ฟัง

ข้าพเจ้าเคยเขียนหนังสือที่เรียกว่า "คู่มือจริยวัตร" ถวายแด่พระเจ้าติโลกราช และพระเจ้าติโลกราชพระองค์นั้นเอง ก็คือผู้ที่สร้างวัดเจ็ดยอดแห่งนี้ พอนึกดูว่าคนที่ข้าพเจ้าเคยถวายคำแนะนำ ภายหลังได้ทรงสร้างวัดใหญ่โตเช่นนี้ไว้ ก็รู้สึกประหลาดใจอยู่ไม่น้อย

แม้หลังจากข้าพเจ้าจากไปแล้ว เรื่องราวของวัดแห่งนี้ก็ยังคงดำเนินต่อไป ในปี พ.ศ. 2054 มีพิธีผูกพัทธสีมาจัดขึ้นที่วัดแห่งนี้ แต่ในรายชื่อพระสงฆ์ราวยี่สิบรูปที่เข้าร่วมพิธี กลับไม่มีพระรูปใดเลยที่มาจากเชียงใหม่ เล่ากันว่าภายหลังนักวิชาการถกเถียงกันเรื่องรายชื่อนี้ ว่าใครกันแน่ที่เป็นผู้แต่งบันทึกโบราณเล่มหนึ่ง บอกตามตรงว่าข้าพเจ้าเองก็ไม่ทราบคำตอบนั้นเหมือนกัน ข้าพเจ้าเป็นเพียงผู้ที่เคยรู้จักกษัตริย์ผู้สร้างวัดแห่งนี้เท่านั้นเอง
