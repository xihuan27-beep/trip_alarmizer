我是达拉拉斯米。生为清迈的公主,后来成为暹罗的王妃。今天想跟你讲一个关于这座山的小故事——因塔农山。这座山的名字里,藏着我的父亲。

先说一个有意思的事实。我父亲的名字"因塔农",其实并不是他生下来就有的名字。那是1870年,他即位时获得的称号——而且不是靠血统继承来的,而是按照当时"女婿继位"的习俗得来的。所以"因塔农"这个名字本身,就是一个靠婚姻、而不是靠出身获得的身份。

1914年,我把父亲的骨灰安葬在一座叫昂堪山的山顶。我还把那座山改了名字,以他的名字命名——因塔农山。

想想还挺奇妙的。一个靠婚姻得来的名字,后来又经过女儿的手,变成了一座山永远的名字。名字也好,记忆也好,大概就是这样,一代一代地,以不同的样子传递下去的吧。
