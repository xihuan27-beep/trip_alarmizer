大家好,我是库巴·西威差。是一名僧人,以前人们也叫我"虎僧"。今天想给你们讲讲水安多寺(苏安多寺)的故事。

先跟你说说这座寺庙为什么会在这个位置。早在勐坤那王的年代,就有一条朝圣之路,从旧清迈城墙内出发,经过苏安多城门,再穿过这座寺庙,一直通向杜他农山。这座寺庙正好坐落在这条路上——算是上山途中的一道门户。它还出现在"佛陀巡游世界"的传说里,用的是它的旧名"蒲帕拉姆",被列为八大圣寺之一。

这座寺庙和杜他农山,其实是被同一个传说绑在一起的。很久以前,一位叫苏玛那泰拉的僧人请来一份舍利。在用金瓮清洗的时候,奇迹发生了——舍利突然分成了两三份。其中一份供奉在这座寺庙的大塔里,另一份则被驮在一头白象背上放归山林。没想到那头白象自己一路走上了山,爬到杜他农山顶,长啸三声,就在那儿咽了气。后来,人们就在大象停下的那个地方,建起了今天的杜他农山寺。所以说,这座寺庙和杜他农山寺,其实是同一份舍利分出来的"姊妹寺庙"。

这里还有个有意思的佛像故事。有一尊巨大的佛像,叫帕昭高杜佛,本来是铸来给帕辛寺当主佛的——当年是想拿它当作两个对立教派和解的象征。可惜的是,佛像实在太重了,始终没能运到那座寺庙去。一尊象征"和解"的佛像,却连自己该去的地方都到不了。你知道它现在在哪儿吗?就在这儿,这座寺庙里。去不了原本要去的地方,索性就在这儿安了家。

1908年到1909年之间,还发生过一件事——换算成中国的年号,大概是光绪三十四年到宣统元年,也就是末代皇帝溥仪刚登基前后。原本坐落在宾河西岸——也就是今天水安多市场附近——的王室墓地,因为老是被水淹,达拉拉斯米王妃便亲自出面,主持并出资把它迁到了这里。她办了整整十五天的庆典,花费高达十万铢——在当时可是一项了不得的"现代化工程"。从卡威拉王算起,一共有二十位先人的骨灰一同迁葬于此。不过话说回来,达拉拉斯米那些年推行的各项"现代化"工程,在当地民间也一直伴随着不太吉利的议论。

不过这里有个特别让人感慨的反转。达拉拉斯米当年为别人修了这座安息之地,没想到多年之后,她自己也被安葬在了同一座墓园里。她曾为别人张罗归宿,到头来,自己也躺在了那里。

1931年7月9日,这座寺庙的大殿——威汉銮殿动工修建。每天都有六七千人跑来帮忙出力,一座五十六根柱子、25米乘66米的大殿,前后只用了八个月就完工了。可以说,这是全城的人一起盖起来的一座寺庙。

差不多同一时期——也就是中华民国时期,九一八事变前后——我也和这座寺庙结下了缘分。跟我修过的其他寺庙一样,这儿的屋檐博风板上也留着老虎图案,那是我的"签名"。

1938年2月21日,我去世了。不过有意思的是,我的荼毗(火化)仪式,一直拖到整整八年后的1946年3月21日才举行。具体为什么拖了这么久,说实话我自己也不太清楚。后来,我的舍利被分成七份,供奉在不同的地方,其中一份就在这座水安多寺。

最后再告诉你一件事。这座寺庙至今还有一个叫"和尚聊天"的项目,大约十位僧人,会跟三四十位游客坐下来聊上两个小时。想想看,我这辈子也从没拒绝过和陌生人交谈,某种意义上,这样的对话如今还在这座寺庙里继续着。你要是正好在这儿,不妨也找机会跟一位真正的僧人聊聊。

对了,还有一件事——还记得我提到的那座"姊妹寺庙"杜他农山吗?我活着的时候,上山的那条路,也是我修的。要是你之后也打算去那儿,在那边也能听到更多关于我的故事。
