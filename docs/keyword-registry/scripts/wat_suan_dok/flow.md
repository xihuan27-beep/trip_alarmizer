**화자: 크루바 시위차이 (동일 인물, 다른 두 사이트와 순서 무관)** — 사후 사리 7분의 1이 이곳에 봉안되어 있고(`khruba_srivichai_relic_distribution`), 호랑이 문양도 여기 남아있어(`tiger_signature`) 3번째 등장지로 적합. 옛 전설(쿠에나왕 순례길, 수마나테라 사리 전설, 왕실묘 이장)은 "전해 들은 이야기"로, 자신의 사후 처리(사리 분배)는 코다로. 자기소개·다라 라사미 소개는 이번에도 완전히 새로 — 순서 가정 금지 규칙 그대로 적용.
