我是遮玛提毗。据说我是建立并统治了哈利奔猜的女王。今天想跟你讲讲我与这座寺庙——瓦帕塔哈利奔猜寺之间的故事。

说实话,我统治这片土地的过程,并不算光明正大。当年我曾为了这片土地,与一个名叫威兰迦的巨人进行了一场掷矛比赛,而我用了诡计才将他制服。我承认那不是什么光明磊落的手段。但正是靠着这样的方式,我才掌控了这片土地,建立起哈利奔猜王国。

就连我这样建立起来的王国,也没能永远延续下去。后来,一位名叫孟莱的国王征服了哈利奔猜。他带走了这座寺庙里两件最珍贵的宝物。一件是用白玉雕刻而成的塞唐卡玛尼佛,另一件是印度笈多风格制成的那罗祇利调伏像。我比任何人都清楚,征服者从被征服的土地上带走最神圣之物意味着什么——那不仅仅是夺走一件物品,而是在宣告"如今这片土地的灵性力量也归我所有"。我所建立王国中最珍贵的东西,就这样成了别人的东西。

我听说,那两尊佛像如今被供奉在清迈的一座寺庙里。如果你好奇的话,不妨也去那里看看。
