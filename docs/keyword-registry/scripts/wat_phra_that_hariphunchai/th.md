ข้าพเจ้าคือพระนางจามเทวี ผู้ที่เล่าขานกันว่าเป็นผู้สร้างและปกครองหริภุญชัย วันนี้ขอเล่าเรื่องราวของข้าพเจ้าที่ผูกพันกับวัดนี้ วัดพระธาตุหริภุญชัย ให้ฟัง

ถ้าจะให้พูดตรงๆ การที่ข้าพเจ้าได้ปกครองดินแดนแห่งนี้ ก็ไม่ได้มาอย่างยุติธรรมเสียทีเดียว ครั้งหนึ่งเคยมีการแข่งขันพุ่งหอกเพื่อแย่งชิงดินแดนนี้กับยักษ์ตนหนึ่งชื่อวิรังคะ และข้าพเจ้าก็ใช้เล่ห์เหลี่ยมเอาชนะเขาได้ ข้าพเจ้ายอมรับว่ามันไม่ใช่วิธีที่ซื่อตรงนัก แต่ก็ด้วยวิธีนั้นเอง ข้าพเจ้าจึงได้ครอบครองดินแดนแห่งนี้ และสามารถสร้างหริภุญชัยขึ้นมาได้

แม้แต่อาณาจักรที่ข้าพเจ้าสร้างขึ้นมาด้วยวิธีนั้น ก็ไม่ได้คงอยู่ตลอดไป ภายหลังพระเจ้ามังรายทรงพิชิตหริภุญชัยได้ และพระองค์ก็ทรงนำสมบัติล้ำค่าที่สุดสองชิ้นซึ่งเคยประดิษฐานอยู่ในวัดนี้ไป ชิ้นหนึ่งคือพระเสตังคมณี ที่แกะสลักจากหยกขาว อีกชิ้นคือพระพุทธรูปปางทรมานช้างนาฬาคิรี ที่สร้างขึ้นในศิลปะแบบคุปตะของอินเดีย ข้าพเจ้าเข้าใจดีกว่าใครว่าการที่ผู้พิชิตนำสิ่งศักดิ์สิทธิ์ที่สุดจากดินแดนที่ถูกพิชิตไปนั้นหมายความว่าอย่างไร มันไม่ใช่แค่การนำสิ่งของไป แต่เป็นการประกาศว่า "บัดนี้พลังศักดิ์สิทธิ์ของดินแดนนี้ก็เป็นของข้าแล้วเช่นกัน" สิ่งที่ล้ำค่าที่สุดของอาณาจักรที่ข้าพเจ้าสร้างขึ้น ก็กลายเป็นของผู้อื่นไปเช่นนี้เอง

ข้าพเจ้าได้ยินมาว่า ทุกวันนี้พระพุทธรูปทั้งสององค์นั้นประดิษฐานอยู่ที่วัดแห่งหนึ่งในเชียงใหม่ หากท่านสนใจ ลองไปเยี่ยมชมที่นั่นดูก็ได้
