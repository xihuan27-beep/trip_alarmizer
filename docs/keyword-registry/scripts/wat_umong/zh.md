我叫帖拉·詹。曾经是一位学问僧。今天想跟你讲讲这座寺庙——乌蒙寺的故事。不过在这之前,有件事得先跟你说清楚——这段故事里,有相当一部分并不确定。不只是我自己不确定,后世的学者们也一样。这份不确定,我也会老老实实地一并告诉你。

先说说我是怎么变成这样的吧。我曾在杜他农山从一位女神那里获得了智慧。可得到智慧之后,我似乎并不够谦卑。作为惩罚,我被下了诅咒——将来有一天会发疯。所以说,我现在跟你讲的这个故事,其实是一个明明预感到自己终将陷入疯狂,却依然没有停止学习和教导的人的故事。

1380年代中期,古纳王邀请我来到这里。那时候,这片地上长着十一丛竹子,所以这里被称为"韦鲁卡塔兰姆",意思是"竹林寺"。不过说实话,你现在站着的这座寺庙,是不是真的就是当年那座韦鲁卡塔兰姆,我自己也说不准。留存下来的,只有一些间接的证据。

后来,我先后侍奉了两位国王,担任顾问——先是古纳王,后来是提洛卡拉王。为提洛卡拉王,我还写过一部叫作《行仪指南》的书。

到我七十七岁那年,大约是1445年——如果按欧洲的时间来说,差不多是古腾堡正在钻研活字印刷术的那段日子——我去世了。可我去世的地方,史料上另外记作"乌蒙诺伊寺"。那到底是不是眼前这座寺庙,还是完全是另一处地方,说实话,我自己也说不清楚。

再跟你讲件有意思的事。传说这座寺庙是孟莱王在1300年前后建立的,可如果真去看壁画和佛塔的样式,看起来实际上是1380年到16世纪中叶之间的东西。作为一个学者,我得说——传说和实际证据这样对不上号的时候,还挺有意思的。

最后,我再坦白一件事。刚才我讲给你听的这一切,其实全都依托于一份文献。它叫作《般诃·帖拉·詹》手抄本,原本早已失传,如今流传下来的,只是后人的抄本。这份抄本编排得不算按年代顺序,里面也确实存在一些错误。所以说,你刚刚听到的我这一整段故事,说到底,不过是悬系在这样一本单薄又不完整的抄本之上。

即便在我去世之后,这座寺庙也经历了不少事。大约1900年前后遭到盗掘,后来从1948年起,一位名叫昭春·希罗洛的人开始主持修复。可就在修复工作清理泥沙的过程中,壁画的下半部分又一次遗失了。本该是抢救的工作,却又一次让一部分东西悄然流逝。

一个获得了智慧却不够谦卑、因此被诅咒发疯的人,连他留下的记载,最终也只剩一部残缺的抄本——也许,这才是最配得上这座寺庙的结局吧。
