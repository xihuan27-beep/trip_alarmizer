大家好,我是库巴·西威差。是一名僧人,以前人们也叫我"虎僧"。今天我想给你们讲讲我这辈子待得最久的一座寺庙——帕辛寺(王狮寺)。

先跟你说个有意思的事。这个地方,现在被认为是清迈最神圣的寺庙之一,你知道它以前是干嘛的吗?就是个市场。一直到14世纪中叶,这里才建起了寺庙。

这座寺庙的名字,来自它最重要的宝物——帕辛佛像。关于这尊佛像,有一个传说。据说1256年,它从锡兰(也就是今天的斯里兰卡)由船运出发,途中船只遇难,佛像被海浪冲得在海上漂了整整三天,最后漂到了那空是贪玛叻的海岸。

不过,真正的历史记载讲的是另一个版本。佛像最早其实在甘烹碧,后来一个叫陶·玛哈蒲隆的人把它带到了清莱,他的侄子——森勐玛王——又在1385年到1390年之间,把佛像迎请到了清迈。差不多同一时期,欧洲那边,乔叟刚开始动笔写《坎特伯雷故事集》——说来也巧,那也是一部由一个个故事口耳相传、汇集而成的书。你可以把传说和史实,当成同一尊佛像故事里的两个不同章节,而不是互相矛盾的说法。

再跟你讲个有意思的插曲。帕辛佛像被带到清莱的时候,其实还有一尊"姊妹佛像"跟它一起。那就是现在被视为泰国最神圣的宝物——翡翠佛。那尊佛像有一段时间被藏在清莱一座佛塔的灰泥壁里,谁也不知道,直到提洛卡拉王在位期间才被发现。现在它供奉在曼谷的王宫里,但曾经,它就藏在离这儿不远的地方。

帕辛寺和杜他农山的圣物、因塔坤石柱,一起并列为清迈的三大圣物。这说明这座寺庙在整座城市的信仰体系里,占据着多么特殊的位置。

1504年,这里还发生过一件事。帕耶蒂洛王下令铸造了一尊巨大的佛像,叫做帕昭高杜佛,原本打算作为这座寺庙的主佛。为什么要铸这尊佛呢?因为那个年代,水安多派和巴丹派这两个教派之间关系紧张,铸这尊佛像,就是想拿它当作两派和解的象征。可是……佛像实在太重了,始终没能运到这座寺庙来。一尊本该象征"和解"的巨型佛像,最后却因为太重,连自己该去的地方都到不了。现在想想,是不是还挺讽刺的?顺便说一句,兰纳的寺庙习惯把佛塔和大殿沿着东西轴线排开,这可不只是建筑布局,而是把佛教的宇宙观直接建进了砖瓦里。

好了,该说说我自己的部分了。我和这座寺庙结缘,其实并不是偶然。有一位王妃,叫达拉拉斯米,她一辈子都在坚守王室传统,非常有名。人们常常把她和我说成是两个截然相反的象征——她是传统的守护者,我是站在老百姓一边的叛逆僧人。可事实是,亲自点名请我来重修这座寺庙的人,正是她。别的寺庙她托付给了别的僧人,唯独这一座,指名要我来。是不是挺有意思?两个被说成截然相反的象征,骨子里其实这样纠缠在一起。

就这样,我成了这座寺庙事实上的住持。整个二十世纪二三十年代,我都以这里为据点,领导了后来被称为"虎团"的改革运动。这里才是我真正生活、教学、安身立命的家。

可是1935年到1936年之间,发生了一段真正艰难的日子。将近一千名跟随我的僧人和沙弥,被强制还俗。这件事一直拖到1936年4月21日,大家签署誓约书之后才算了结。"改革"也好,"抵抗"也好,这些词都装不下——那是关乎一千个人一生的大事。

就在那场风波正中央,1935年11月1日,我最终在这座寺庙里被捕。据说,那天官府突袭的时候,几个年幼的沙弥躲进了莱堪殿佛坛底下。后来其中一人回忆起那天——在又黑又窄的佛坛底下,屏住呼吸,只等着脚步声渐渐远去。

那以后,我又活了几年,1938年去世。不过有意思的是,你现在要是去这座寺庙的大殿看看,会看到达拉拉斯米的画像,和几位男性王族的画像并排挂在一起。人们常把我称作反抗的象征,把她称作传统的守护者,可到头来,她和我其实就这样安安静静地,共处在同一座大殿里。

对了,还有一件事——我去世之后,我的舍利被分成七份,供奉在不同的地方,其中一份就在水安多寺。如果你之后也打算去那儿看看,在那边也能听到更多关于我的故事。
