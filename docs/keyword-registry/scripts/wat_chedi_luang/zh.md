我是一名僧人,在这座寺庙——契迪龙寺——已经守了很久很久。说实话,连我自己也说不清究竟是从什么时候开始的,这个故事就是这么古老。今天,我想跟你讲讲这座寺庙的故事。

如今大家叫它"契迪龙寺",可在拥有这个名字之前,它还有过好几个名字。瓦乔提卡兰寺、瓦叻查普提干寺、瓦叻查古塔兰姆寺——每个时代,人们叫它的名字都不一样。以"乔提卡兰"这个名字,它还出现在"佛陀巡游世界"的传说里,是八大圣寺之一。

和其他兰纳寺庙一样,这座寺庙也是把佛塔立在中央,大殿沿着同一条轴线朝东排开。这可不只是建筑布局而已——这是以须弥山为中心的佛教宇宙观,加上围绕九大行星的占星学说,实实在在地凝固在了砖石之中。

不过,这座寺庙历史上最重要的一件事,发生在1545年——换算成中国的年号,大概是明世宗嘉靖二十四年。那一年,一场大地震袭来,这座寺庙的大塔——当年兰纳境内最高的建筑之一——塔尖轰然崩塌。从那以后一直到今天,这座塔都没能完全修复。你现在看到的这副"未完成"的轮廓,其实正是那场几百年前的灾难留下的痕迹。

不过有意思的是,这座塔身残缺的寺庙,后来反倒成了整座城市的信仰中心。1800年,卡威拉王把被称为"因塔坤"的城市中柱,从瓦萨杜勐寺迁到了这里——换算成中国的年号,大概是清仁宗嘉庆五年。从那天起,这座并不完整的寺庙,反倒占据了整座城市最核心的位置。直到今天,这根因塔坤石柱依然和杜他农山的圣物、帕辛佛像一起,并称为清迈的三大圣物。

到了20世纪60年代,又发生了一次变化。市政厅正式接管了因塔坤仪式,原本融合其中的灵媒元素,则被分离出去,迁到了一个叫贞斯里蓬的地方。曾经合而为一的一场仪式,随着时间推移,分成了两支——一支是官方的佛教礼仪,另一支则是民间的灵媒信仰。

回头看看,这座寺庙实在是个充满反讽意味的地方。它最高的那座塔倒塌之后,再也没能恢复完整——可恰恰是在那次残缺之后,它才赢得了全城最神圣的位置。造就这个中心的,不是完美,而恰恰是那道伤痕。

对了,还有一件事——20世纪60年代从因塔坤仪式中分离出去的灵媒信仰,如今依然延续在一个叫贞斯里蓬的地方。要是你之后也打算去那儿,在那边也能听到更多。
