我是纳瓦拉特桥。在我的一生中,我换了三次"身体"。今天想跟你讲讲这段故事。

我最初诞生于1921年,是一座柚木桥。换算成中国的年号,大约是民国十年——正是两次世界大战之间,法西斯主义在欧洲开始抬头的那段时期。因为是木头做的,我常常吱呀作响,随着岁月流逝,需要修补的地方也越来越多。

就在我的南边,有一位有趣的邻居。曼谷在清迈设立的第一个军事驻地,就在宾河东岸,紧挨着我的南侧——那正是今天卡威拉军营所在的地方。我就在旁边,看着那些士兵来来往往。

后来,大约在1953年,我换成了第二副身体,这次是铁桥。换算成中国的历史,那正是朝鲜战争(抗美援朝)停战协定签署的那一年。铁比木头结实得多,但也没能永远维持下去。

而你现在脚下踩着的,是我的第三副身体,由钢筋混凝土建成。从木头到铁,再从铁到混凝土——我就这样跟着时代不断更换身体,却始终守在这同一个地方。

不过,我最怀念的,其实是1964年前后的一幕景象。那时候一到旱季,宾河的水位就会降到只到膝盖的高度。人们便会在宋干节涉过那片浅浅的河水,一起嬉水玩耍。老照片里留下的那一幕,我就在这里亲眼见证过。可自从水坝建成后,河水水位常年维持在高位,那份朴素的景象,如今再也看不到了。
