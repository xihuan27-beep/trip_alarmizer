我是昭诺·苏卡森,清迈王室的侄辈。今天想跟你讲讲你现在所站的这座城门——素贴门的故事。

早在我出生之前,这座城门就已经扮演着特殊的角色。曾经有一条朝圣之路,从古代的维恩清迈出发,经过这座城门,再到一座名叫瓦布帕拉姆的寺庙——也就是今天的素贴寺——一路延伸到素贴山。据说这一传统可以追溯到孔纳王的时代。而这座城门,正是那条古老朝圣之路的起点。

但我永远无法忘记的,是1903年发生的事。换算成中国的年号,大约是光绪二十九年,也正是莱特兄弟首次实现动力飞行成功的那一年。我不得不因为政治原因,送走我的缅甸情人玛米亚。而那场离别,就发生在这里——这座西城门,也就是你现在所站的地方。这个故事如今几乎被当作传说流传,但那却是我亲身经历的事。

后来,又过了很久很久,到了2021年,发生了一件有趣的事。学者们在研究从卡威拉王到达拉拉萨米、共计二十人的王室墓葬名单时,在其中发现了"昭乌达拉干·科松"这个名字。那正是我。我曾长期被当作只存在于传说中的人物,直到那时,后世的学者才确认,我其实是一个真实存在、有据可查的人。

顺便说一句,当年安放我遗骸的那座王室墓,后来是由达拉拉萨米亲自主导迁走的。若想了解那次迁葬的故事,不妨去瓦洛洛市场听听看。
