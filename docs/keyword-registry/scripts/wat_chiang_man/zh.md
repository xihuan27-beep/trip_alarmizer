# 契迪·清曼寺 (中文)

清曼寺是清迈最古老的寺庙，某种意义上，它就是这座城市的"创业办公室"。

1296年，雄心勃勃的孟莱王与帕尧的岸孟王、素可泰的銮王结盟，共同勘察新都城的选址。这座寺庙至今保存的建寺碑文上，明确刻着三位国王共同创立此寺。按照兰纳古老的信仰——"建城必先建寺，以此为城之根基"——这座寺庙被命名为"清曼"，意为"坚固之城"。那一年，元朝成宗铁穆耳在位，年号元贞二年。

国王刚刚征服了哈利奔猜王国，便将两尊珍贵的佛像迎请至此：一尊是用白玉雕成的塞塘卡玛尼佛，另一尊是印度笈多风格的"降伏那罗祇厘象"石雕佛像。这座寺庙还出现在"佛陀巡游世界"传说中的八大圣寺之列——足见清曼寺自建寺之初，便在清迈的宗教版图中占据着何等特殊的地位。

约170年后的1471年，提洛卡拉王重建了倒塌的第一座佛塔，塔基被十五尊大象雕像环绕，称为"象绕佛塔"。（此时正值明宪宗成化七年。）

然而荣光并未持续太久。1551年，清迈沦陷于缅甸军队之手，这座寺庙也随之荒废。（此时为明世宗嘉靖三十年。）讽刺的是，仅仅七年后的1558年，正是这位占领者——缅甸王孟德拉——反而大力资助重修了这座寺庙，成为征服者守护被征服者信仰的罕见一例。（嘉靖三十七年。）

*（学者笔记：一块刻于1581年的碑文声称，早在1296年这座寺庙就已建有"三重城墙"，但这一说法未见于任何其他编年史，学界因此怀疑这可能是后世附会的传说。此时正值明神宗万历九年。）*

近500年后，1797年3月9日星期四——恰好是孟莱王建城五百周年纪念日当天，卡维拉王驱逐缅甸人，凯旋归来，重新踏入这座长久空寂的清迈城。在正式进入王宫的前一夜，他选择在这座寺庙前留宿一晚。此后，卡维拉推行了著名的"聚人如聚菜入篮"政策，召回四散的百姓，重建了这座城市。（此时为清朝嘉庆二年。）

19世纪末，达摩育提迦派的僧侣首次在清迈定居于此。（正值清朝光绪年间。）

1909年，达拉拉斯米王妃将寺中一尊佛像请去了曼谷。巧合的是，两个月后，她的异母兄长、时任清迈总督的因塔瓦洛罗突然去世，当地民众私下议论，认为这正是那次"请走佛像"招致的不祥业报。（此时为清朝宣统年间。）

1920至1930年代，这座寺庙又成为另一段故事的舞台。生于虎年的僧人库巴·西威差以此为据点，领导了后来被称为"虎团"的改革运动。经他修缮的建筑上，至今仍留有老虎图案，被视为他独特的"签名"。他一度还因被指控持有"带金鞘的神剑"而遭调查——这项指控隐隐暗示着谋反之意。至于他究竟何时、因何首次被捕，学界至今仍有争议：传统说法认为是1908至1910年间因违反僧伽法，而近年的研究则认为实际发生在1915年前后，缘由是违反兵役法。（此时正值中华民国时期。）

他圆寂24年后的1962年，寺内建起了纪念他的堂宇。（此时中华人民共和国正处于大跃进之后的调整时期。）

今天的清曼寺，并存着两种截然不同的象征——守护王室传统的达拉拉斯米，与站在民众一边的反抗僧侣库巴·西威差。七百多年间，这座小小的寺庙承载了一座城市从诞生、沦陷到光复，从王室到民间的全部故事。
