我是很久以前从清盛被带到这里的战俘之一。今天想跟你讲讲我与这座城门——塔佩门之间的故事。

我原本是清盛人。但在一场战争中战败被俘,被强行迁到这里安置,就在城墙东南角,靠近这座塔佩门的地方。不只是我们,一个孟族社区也在附近安顿下来。这些原本并非自愿来到此地的人们,不知不觉间竟成了邻居。

很久很久以后,到了2002年,发生了一件有意思的事。从这座塔佩门通往乌帕库特寺的这段路上,开始出现了"步行街"——一个每逢星期日举办的集市。这个地方,曾经是像我这样的人被迫在陌生土地上安家落户之处,如今却成了人潮涌动、热闹非凡的商业街。对我而言,这感觉莫名地贴切。

从2013年起,我又看到了另一番景象。一项名为"向孟莱王致敬"的仪式得以复兴,每年4月11日和12日,都会有一支巡游队伍从这座城门——也就是东侧的起点——出发,一路走到三王像广场。参加指甲舞的人数也大幅增长,从2014年的150人涨到了2019年的850人。仔细想想,这实在有些讽刺。我当年是被迫带到这里、在这座城门附近定居下来的,而如今,人们却心甘情愿地从这同一座城门出发,步行前去向国王表达敬意。
