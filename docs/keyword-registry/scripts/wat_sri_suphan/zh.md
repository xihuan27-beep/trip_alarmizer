我是在这座寺庙附近的银匠村里工作的一名银匠。今天想跟你简短讲讲这座寺庙——诗素攀寺的故事。

我们做银器的手艺,容不得一丝一毫的误差。有意思的是,这座寺庙的维汉,也就是正殿,最初动工的那一刻,竟然被记录得异常精确。据说是在1503年——换算成中国的年号,大约是明孝宗弘治十六年——用欧洲的时间来说,正是列奥纳多·达·芬奇刚开始绘制《蒙娜丽莎》的那段时期——按朱拉萨卡拉特历是865年的新年,星期四清晨六点到七点半之间。竟然连具体到几点几分的记录都留了下来,对我这种做精细活儿的人来说,总觉得莫名地有共鸣。

而我之所以会在这一带做银器,还有另一段渊源。后来卡威拉王推行了"把菜装进篮子里,把人安顿进城里"的政策,把泰允族、泰坤族、泰永族、拉瓦族和孟族这五个族群安置在了这片地区。当年定居下来的人们那双双巧手,经过一代又一代的积累,才让整个这片街区如今以银匠村而闻名。我也是继承了这门代代相传手艺的人之一。
