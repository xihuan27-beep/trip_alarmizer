저희 은세공 일은 아주 작은 오차도 허용하지 않는 일이에요. 그런데 재밌게도, 이 절의 위한, 그러니까 법당을 처음 짓기 시작한 순간이 놀랍도록 정확하게 기록으로 남아있습니다. 1503년, 쭐라삭까랏력으로는 865년 신년, 목요일 오전 6시부터 7시 반 사이였다고 해요. 여러분이 아시는 시대로 치면, 레오나르도 다빈치가 모나리자를 그리기 시작할 무렵이었죠. 몇 시 몇 분까지 정확히 남아있는 기록이라니, 저처럼 세밀한 작업을 하는 사람 입장에서는 왠지 마음이 가는 이야기예요.
