# 왓 파댕 유적 — 스토리 흐름 (언어 중립 비트시트)

`site_id = wat_pa_daeng_ruins`, `site_links` 기준 6개 키워드. wat_umong과 마찬가지로 "저자의 정체가 불확실한 사료" 소재지만, 톤은 다르게 — 저주받은 비극이 아니라 "역사를 기록한 사람이 정작 역사 속에서 사라졌다"는 역사학적 아이러니.
