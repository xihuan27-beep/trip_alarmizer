我是乌本完娜。生为清迈国王卡威洛叻的幼女。今天想跟你讲讲这座宅邸的故事,这是我曾经居住的地方。我的一生,与其说和王室有关,不如说更多和经商、和当灵媒有关。

先跟你说说我是个什么样的人。在这儿,我同时经营着织布作坊、木材生意、木雕、漆器厂,还有一家酿酒坊。我和来自美国、英国、斯堪的纳维亚、缅甸的商人都保持着贸易往来,英语也说得相当不错。有一次,我在这座宅邸的阳台上,亲自给一位英国来客演示织布,当场就接到了一份英国花边的订单。虽然生为公主,但我活成了一个名副其实的国际商人。

这里还有件事值得一提。前任乌帕拉,也就是副王,分他翁大人,是因鸦片过量而去世的,而发现他遗体的人,正是我。可后来,我成了我们家族的灵媒,负责的,恰恰就是把他的魂魄请回来、替他传话。发现他死讯的人,后来成了替他发声的人。

作为灵媒,我请回了他的魂魄,建议废除酒税——也就是那项烧酒专卖税。令人意外的是,1884年,暹罗政府真的废除了这项税收。一场灵媒仪式,竟然带来了实实在在的政策改变,这样的例子并不多见。

1881年,还发生过这样一件事——换算成中国的年号,大概是光绪七年,也就是留美幼童被召回的那一年。我卷入了后来被称为"蒙庞雅案"的事件。我当时爱着的人,是一位持有英国国籍的缅甸商人,后来他被发现离奇死亡。我最终成了治外法权法庭上十名被告之一。这是一桩把生意、爱情和国际法都搅在一起的案子。

1884年,我姐姐提贝功病重,病情危急。围绕着她的病,传统灵媒派和信奉西医的一派之间展开了一场角力。那是一段相当混乱的时期——灵媒仪式和关于抗税的谈判,几乎是同时进行的。姐姐的去世,对我来说不只是个人的丧失,更是一场政治上的风暴。

姐姐去世后,我收养了年幼的外甥女达拉拉斯米。那时她才十一岁。可是巧的是,就在同一年,我自己也去世了。失去姐姐、收养外甥女、自己也离开人世——那真是动荡不安的一年。

不过有意思的是,故事到这儿还没完。我去世之后,轮到我的孩子——卡威洛翁和蕾努完娜——被那个曾经年幼的外甥女达拉拉斯米收养、抚养长大。就像我曾经照顾过她一样,她长大后也反过来照顾了我的孩子。隔了一代人,那份照拂又原样转回来了。我对织布的兴趣,也是这样传给了她。

回过头看,我的一生,是王室血统和商人的胆识、灵媒身份的神秘与丑闻,还有对家族的责任感,全都交织在一起的时光。短暂而激烈,可它的痕迹,却这样一代一代地,继续传了下去。
