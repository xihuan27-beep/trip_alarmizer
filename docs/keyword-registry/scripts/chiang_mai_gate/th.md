ข้าคือประตูเชียงใหม่ ยืนอยู่ที่มุมกำแพงเมืองด้านตะวันออกเฉียงใต้ วันนี้จะขอเล่าเรื่องสั้นๆ ที่ผูกพันกับชื่อของข้าให้ฟัง

จริงๆ แล้วข้าไม่ได้ถูกเรียกว่า "ประตูเชียงใหม่" มาตั้งแต่แรก เมื่อนานมาแล้ว ข้าเคยถูกเรียกด้วยชื่อ "ประตูท้ายเวียง" เมื่อเวลาผ่านไป ชื่อที่ผู้คนใช้เรียกข้าก็เปลี่ยนไปด้วย จนตอนนี้ทุกคนก็เรียกข้าง่ายๆ ว่าประตูเชียงใหม่ แม้แต่ชื่อเพียงชื่อเดียว ก็ยังมีร่องรอยของกาลเวลาฝังอยู่เช่นนี้
