# 언어별 비교 시간대 앵커 (재사용 레퍼런스)

각 사이트 스크립트를 9개 언어로 쓸 때, 절대연도 대신 독자에게 익숙한 비교 시점을 곁들이는 장치입니다. 앵커는 **한 번 정하면 모든 사이트에서 재사용**하고, 새 연도가 필요할 때만 이 표에 추가합니다.

- **한국어**: 한국사(조선/고려/대한제국/일제강점기/대한민국) 기준
- **중국어**: 중국사(원/명/청/중화민국/중화인민공화국) 기준
- **영어·스페인어·독일어·프랑스어·이태리어·러시아어**: **공통 유럽사 앵커 하나**를 언어별로 번역만 다르게 사용 (국가별로 따로 만들지 않음)
- **태국어**: 비교 없음 — 이미 현지 역사이므로 절대연도만 자연스럽게 서술

## 사용 원칙 (2025-09 개정)

1. **앵커는 매 비트마다 넣지 않는다.** 사이트당 보통 2~3곳, 정말 인상적이거나(예: 시대적 우연이 두드러지는 지점) 독자의 시간 감각을 처음 잡아줘야 하는 지점(대개 창건 연도)에만 쓴다. 기계적으로 문단마다 괄호를 다는 것은 금지.
2. 괄호로 딱 끊어 넣기보다, 화자가 독자에게 말을 거는 삽입구로 자연스럽게 녹인다 — 예: "여러분이 아시는 시대로 치면, ~~ 시절이었지요." 매번 같은 패턴을 반복하지 말고 문장 안에 자연스럽게 섞어도 된다.
3. 같은 연도가 여러 사이트에 등장하면 이 표의 사실관계(어느 왕·사건인지)는 재사용하되, 문장 표현은 화자·맥락에 맞게 매번 다시 써도 된다 — 토씨 하나까지 복붙할 필요는 없음.
4. 새 연도가 필요하면 이 표에 먼저 행을 추가하고, 그 다음 스크립트에 반영한다.
5. 태국어 스크립트는 앵커를 넣지 않는다.
